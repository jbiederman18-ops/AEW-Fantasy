Database Connection

      

        One-time setup
        
    
          
  1. Create a project at console.firebase.google.com
    2. 
          
  2. Build → Realtime Database → Create database. Pick the region closest to you.
    3. 
          
  3. Build → Authentication → Get started → enable Anonymous
    4. 
          
  4. Project settings → Your apps → Web → register, then copy the config block and paste it below
    5. 
          
  5. Realtime Database → Rules → paste the rules below → Publish
    6. 
        

        
Publish the rules even if the database is in test mode. Test mode expires on a date you did not choose, and when it does the app stops saving mid-show.

Start New Season

      
A new season is a new id under the same database. Every phone switches to it automatically — nothing to redeploy or send round. Pick a short id with no spaces. Entering the id of an existing season switches everyone back to it instead.
